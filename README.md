# Legal task skills for Codex

- [legal-task-review](legal-task-review/SKILL.md) assesses legal evaluation packages and validates that the prose pass preserves the review's decisions.
- [legal-task-revise](legal-task-revise/SKILL.md) repairs evaluation packages after review and verifies the revised Word work product.

Copy each skill directory in full to your Codex skills directory. Each includes its working references and utility scripts. The utilities run with Python 3. The review workflow uses the separate `humanizer` skill. Both workflows use Codex document, PDF, or spreadsheet skills as needed for the supplied files.

The revision skill includes a Markdown summary of the Round 2 guidance. Consult the original project PDF if you have access to it.
